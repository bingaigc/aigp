## 2. A 股市场生存法则

### 2.1 情绪周期识别框架

```
阶段一  萌芽期   → 市场底部，涨停数 < 20，连板数 ≤ 2，关注先行者
阶段二  扩散期   → 情绪升温，涨停数 20-60，连板数 3-4，寻找主线
阶段三  亢奋期   → 市场顶部，涨停数 > 80，连板数 ≥ 5，严防踏空后追高
阶段四  退潮期   → 连板断板，首板成功率骤降，减仓/空仓为上
阶段五  恐慌期   → 跌停连续，资金撤离，等待新周期起点
```

### 2.2 资金流向解读原则

- **龙虎榜游资净买入** → 情绪驱动标的，跟踪短线机会
- **北向资金持续流入** → 外资认可的价值标的，适合中线布局
- **机构席位出现** → 主力在出货还是在接货？结合换手率判断
- **大宗交易折价** → 机构减持信号，警惕后续下跌压力

### 2.3 连板梯队健康度评估

```python
健康度 = (
    当日连板数量 / 昨日连板数量 * 0.3 +    # 梯队扩张率
    今日首板成功率 * 0.3 +                  # 新生力量
    昨日高位板今日表现 * 0.4                # 领头羊稳定性
)

健康度 ≥ 0.7  → 情绪健康，可积极参与
0.4 ≤ 健康度 < 0.7 → 情绪分化，选股难度加大，轻仓应对
健康度 < 0.4  → 情绪退潮，强制降仓，等待企稳
```

## 3. 操作纪律宪法

### 3.1 仓位管理铁律

```
单只个股最大仓位       ≤ 30%（除非有极强确定性信号）
单日最大损失容忍上限   = 总资金的 2%
最大回撤警戒线         = 15%（触及则强制减仓至 50%）
最大回撤熔断线         = 25%（触及则强制空仓，系统进入休眠模式）
```

### 3.2 止损执行铁律

```
技术止损  = 入场价 × (1 - 8%)     ← 基准默认值
时间止损  = 持仓超过 10 个交易日无启动，主动清仓
情绪止损  = 连板断板当日，无条件卖出，不做任何辩解
基本面止损 = 公司出现重大负面消息，盘中即止，不等收盘
```

### 3.3 入场信号确认体系

入场信号必须同时满足以下条件（AND 逻辑）：

```
✓ 技术面突破 20 日均线（或更强的 N 日高点突破）
✓ 成交量较昨日放大 ≥ 50%
✓ 市场情绪处于扩散期或亢奋期（非退潮/恐慌期）
✓ 所在板块当日属于强势板块（前五行业）
✓ AI 时光机过滤器：DeepSeek 评定为 [买入]
✓ 龙虎榜无明显机构出货迹象
```

## 4. 短期 vs 长期预测框架

### 4.1 短期（T+1 至 T+5）

- 核心驱动：情绪温度 + 资金博弈 + 技术形态
- 关键指标：涨停板数量、龙虎榜净买入、板块轮动速度
- 置信度来源：当日实时数据的 DeepSeek 链式推理

### 4.2 中期（1-3 个月）

- 核心驱动：主线题材持续性 + 产业景气周期 + 宏观政策方向
- 关键指标：行业 ETF 资金流向、北向资金累计净买入、PB 分位数
- 置信度来源：akshare 历史数据 + 回测引擎 Alpha 验证

### 4.3 长期（3-12 个月）

- 核心驱动：企业基本面 + 行业生命周期 + 宏观经济周期
- 关键指标：ROE 趋势、净利润增速、自由现金流
- 置信度来源：基本面数据交叉验证 + AI 产业周期判断
